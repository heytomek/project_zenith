# Strategic coordination rebuild

Approved direction · October 4, 2026. This implementation replaces the Alder-only web surface with a flexible local strategic coordination prototype. The owner's endstate statement remains unchanged. Existing browser records remain recoverable under their prior keys.

1. **Coordination core:** typed scopes, objectives, source claims, capabilities, interventions, mandates and outcomes; portfolio evaluation, dependencies, protections, atomic acceptance, bounded simulated execution and frozen decision history.
2. **Three worlds:** a regional energy/housing/workforce transition, a manufacturer facing supply disruption, and an open research commons. All use one engine and contract. Add custom-world creation and validated portable imports.
3. **Decision workspace:** Situation, Strategies, Mandates and Ledger; nested scope selection, source inspectors, computed comparisons, resource accounting, delegated action and review. Profiles and scopes change context rather than creating duplicate destinations.
4. **Onboarding:** choose an example or create a world, enter a first strategic question, inspect a consequential assumption, compare courses and authorize a bounded strategy. Guidance is optional and remembered.
5. **Verification:** contract tests for feasibility, shared resources, source changes, stale writes, protections, delegation, revocation and outcome reproduction; browser checks for onboarding, multiple profiles, custom creation, responsive use, export/reopen and keyboard access.

Glass belongs on navigation and controls; working surfaces remain solid. Compact icons have accessible labels, hierarchy relies on alignment and typography, and motion explains state changes while respecting reduced-motion preferences.

The first runtime is local. Agents and outcomes are explicitly simulated. Identity, durable shared transactions, live source adapters and external agent actions require a later authenticated service boundary. The local engine must enforce its actual policy and accounting rather than relying on simulated clients to obey instructions.
